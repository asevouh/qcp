Bundled fallback fonts (used only when the document font, e.g. Calibri, is missing on the computer):
- ExamArabicFallback-*.ttf : static instances of "Noto Naskh Arabic" (SIL Open Font License 1.1), renamed.
- ExamLatinFallback-*.ttf  : "Carlito" (SIL Open Font License 1.1), metric-compatible with Calibri.
- ExamSymbols-Regular.ttf  : subset of "DejaVu Sans" containing only U+2052 (the Arabic-style percent sign), renamed
                             (Bitstream Vera / DejaVu license). It is embedded into exported Word files.
Calibri itself is NOT bundled (Microsoft font); the program uses the copy installed with Windows/Office.
